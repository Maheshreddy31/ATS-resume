# ATS Resume Expert – Application Tracking System

ATS Resume Expert is a web application built with Streamlit, Python, and generative AI (ChatGroq) to help job seekers improve their resumes and application process. It allows users to upload their resume, enter a job description, and get insights like matching score, skill enhancement suggestions, and a customized cover letter.

# Features

✔ Upload your resume (PDF format)

✔ Enter job description text

✔ Select the role you're applying for

✔ Get resume match score against the job description

✔ Receive skill enhancement suggestions

✔ Generate a tailored cover letter

✔ Beautiful, user-friendly interface with 3D styling

# Tech Stack

Python

Streamlit for UI

PyMuPDF (fitz) to extract text from PDFs

Langchain Groq (ChatGroq) for AI-powered recommendations

AWS, Git, Docker (optional tools you can explore)

Environment variables managed by dotenv

# How it Works

1. Users upload their resume in PDF format.

2. Users paste the job description text.

3. Users select the role they are applying for.

4. The system extracts text from the resume.

5. The AI model (ChatGroq) analyzes the resume and job description.

6. The user can:

      Check how well their resume matches the job.

      Get suggestions to improve skills.

      Generate a customized cover letter.
